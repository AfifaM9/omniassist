# Repository Guidelines

## Git Commit Convention

Every commit message MUST include:

1. A short subject line (the message).
2. A commit description body.
3. A blank line, then the trailer:
   `Co-authored-by: AfifaM9`

Format:

```bash
git commit -m "Message" -m "Description


Co-authored-by: AfifaM9"
```

The description is followed by an empty line (skip one line) before the `Co-authored-by: AfifaM9` trailer.
